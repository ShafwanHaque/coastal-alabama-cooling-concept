# Coastal Alabama Cooling Concept — HVAC Website

A standalone Next.js concept project tailored to Coastal Alabama Cooling. It includes the full `src` app and pnpm lockfile.

## Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project notes

- Business details, palette, services, coverage, and calls to action are in `src/config/site.config.ts`.
- The supplied official logo and hero image are referenced from lirp.cdn-website.com and irp.cdn-website.com. Internet access is required to load those source assets.
- The request form is a preview and does not send submissions. The service-area map uses OpenStreetMap tiles and needs internet access.
- Confirm all business details before publishing.

Original website: https://www.cacooling.com/
